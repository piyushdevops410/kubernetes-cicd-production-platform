# kubernetes-cicd-production-platform
Production-style Kubernetes CI/CD pipeline with Jenkins, Docker, Trivy, and GitHub.

## Development Workflow

This project follows a feature-branch based Git workflow.

### Workflow

Developer
   ↓
Feature Branch
   ↓
Code Changes
   ↓
Commit
   ↓
Push to GitHub
   ↓
Pull Request
   ↓
Code Review
   ↓
Merge to Main
